# AI Interview Trainer 0.7.0

На сторінці входу з'явився чекбокс «Запам'ятати мене» (для входу й реєстрації, вимкнений за замовчуванням) — якщо його позначити, сесія лишається активною довше. Публічна головна сторінка (`/`) тепер показує кнопку «Кабінет» замість «Увійти», якщо ви вже авторизовані.

Виправлено: кнопка на головній сторінці іноді продовжувала показувати «Кабінет» і після виходу з акаунта, доки сторінку не перезавантажували вручну.

Відоме обмеження: чекбокс «Запам'ятати мене» поки не діє для входу через Google — сесія через Google завжди поводиться так, ніби чекбокс не позначений. Деталі в `docs/features/remember-me/STATUS.md`.

# AI Interview Trainer 0.1.1

Невеликий технічний реліз без нових можливостей для користувача.

Ми задокументували в API-специфікаціях кілька ендпоінтів, які вже працювали, але не мали опису: перевірку поточного користувача, історію співбесід і сторінку прогресу. Також виправили внутрішній інструмент, який звіряє код із документацією, — він хибно вважав частину auth-маршрутів недокументованою, і прибрали застарілий, більше не потрібний конфіг автоматизації релізів.
